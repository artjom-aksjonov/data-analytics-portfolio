# Email Marketing Performance Analysis

## Project Overview

This project focuses on analyzing email marketing performance and user engagement across different countries.

The goal was to explore account creation trends, measure email activity, and identify the countries with the highest number of registered accounts and sent emails.

Using SQL in Google BigQuery, I combined account and email activity data to build an analytical dataset that allows performance comparisons across different user segments.

## Key Analysis Areas

- **Account Growth:** Analyzing the number of newly created accounts over time.
- **Email Engagement:** Measuring sent, opened, and clicked email messages.
- **User Segmentation:** Comparing activity based on country, email sending interval, account verification status, and subscription status.
- **Country Performance:** Identifying and ranking countries based on account creation and email sending activity.

## Tools & Technologies

- Google BigQuery
- SQL

## SQL Skills Demonstrated

- Common Table Expressions (CTEs)
- INNER JOIN and LEFT JOIN
- UNION ALL
- Aggregate functions (COUNT, SUM)
- Window functions (SUM OVER, DENSE_RANK)
- Data grouping and segmentation
- Date calculations and transformations

## Key Outcome

The project resulted in a structured analytical dataset that supports comparisons of email marketing activity across countries and user segments, helping identify key markets and understand user engagement patterns.
