# Revenue Analysis by Device and Continent

## Project Overview

This project focuses on analyzing e-commerce revenue across different continents and devices.

The main goal was to understand how revenue is distributed between mobile and desktop users, compare performance across continents, and explore additional metrics related to customer accounts and website sessions.

Using SQL in Google BigQuery, I combined data from multiple tables to create an analytical dataset with key business metrics.

## Key Analysis Areas

- **Revenue Analysis:** Calculating total revenue for each continent.
- **Device Performance:** Comparing revenue generated from mobile and desktop devices.
- **Revenue Contribution:** Calculating each continent's percentage of total revenue.
- **Account Analysis:** Measuring the total number of accounts and verified accounts.
- **Session Analysis:** Comparing website session volumes across continents.

## Tools & Technologies

- Google BigQuery
- SQL

## SQL Skills Demonstrated

- Common Table Expressions (CTEs)
- INNER JOIN
- CASE WHEN
- Aggregate functions (SUM, COUNT)
- Window functions (SUM OVER)
- SAFE_DIVIDE
- Data grouping and aggregation
- Percentage calculations

## Key Outcome

The project resulted in an analytical dataset combining revenue, device, account, and session metrics, providing a foundation for comparing e-commerce performance across different continents.
